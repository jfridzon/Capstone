Here are our Phase 0 and Phase 1 answers for the AI model project we spoke with you about today.

In short, we want to predict which AI model (ChatGPT, Claude, Gemini and others) will give the best answer for a specific type of task, so a company/user knows which model to use for each kind of work instead of using 1 model for everything.

About your question, if a cheaper model can really beat a top one

It can, and it happens more than we expected. We opened 1 of the 7 data files (19,377 votes) and grouped the models by price ourselves. When a cheaper model went against a top model (Claude Opus 4, o3, Gemini 2.5 Pro or Grok 4), the cheaper one won 28% of the time and tied 15% of the time. The ranking also changes depending on the task. In math, Gemini 2.5 Flash, which is a cheap model, came in 3rd, above Claude Opus 4 and o3. In creative writing, Gemma 3, a free model, came in 3rd and was also above Claude Opus 4. So we agree with what you suggested, that the more useful question is which model is best for each task and not just paid vs free. These are early numbers from what we looked at, so they could change once we use the full data.

Phase 0

1. Problem. More companies pay for AI now, and most of them pick 1 model and use it for everything. But each model is better at different things, and their prices are very different. Right now a company chooses by brand name or by a general ranking that treats every task the same. To know which model is best for each task you need records of real people comparing answers from different models on real tasks, and that data already exists.
2. Client. A company that uses AI for its employees' work (coding, writing, analysis, customer questions) and wants to know which model to use for each type of work.
3. Historical data. Yes. LMArena is a public website where a person asks a question, 2 anonymous AI models answer, and the person votes for the better answer. LMArena released 135,634 of these votes from late 2025 for free on Hugging Face. Each row is 1 vote with the question, the 2 models, who won, and labels that describe the question (coding, math, creative writing, complex or not, and others).
4. Is it too difficult to get? No. It's 1 dataset, so we don't have to join different sources together. We already downloaded part of it and checked that all of the columns are there.
5. Success. First, our model should predict the winner on votes it has never seen better than the general ranking does, since the general ranking uses the same order for every task. Second, a simple tool where you choose the type of task and it shows the top 3 models for that task.

What we know we can do, what we want to do, and the goal

* We know we can: predict the winner for each type of task using the data as it is.
* We want to, if possible: add each model's price from the companies' public price pages, so we can also show the best model for the money.
* Goal: a tool a company could actually use, and could run again as new models come out.

Phase 1

1. What we predict. Whether a model's answer gets picked as the better one (won the vote, yes or no), based on the type of task and the model it was compared against.
2. Is it in the data? Yes, explicitly. The column "winner" says model A, model B, tie, or both bad. We will turn each vote into 2 rows, 1 for each model, and mark if that model won. We will also try counting a tie as half a win.
3. Predictors.

Explicitly in the data:

* Which model answered and which model it was up against
* Whether the question involves code
* Whether it is math, creative writing, or a request with specific instructions to follow
* 7 yes/no labels about the question: complex, needs expert knowledge, problem solving, real world, specific, needs technical accuracy, and creative
* The language of the question

From a transformation of the data:

* The company behind each model (OpenAI, Google, Anthropic and others) and if it is a premium version, both taken from the model name
* Language grouped into English questions and non English

From an outside source:

* The price of each model, from public price pages. It's a small table of about 50 models that we would build ourselves.

3a. Known before the decision? Yes. All of these are known before the AI writes its answer, since they only describe the question and the models. The labels on the question were made by looking only at the question. The data also has the length of each answer and how many bullet points, headers and bold words it used, but that is only known after the answer is written, so we won't use it to predict. We might use it to explain why people vote the way they do, for example if people just prefer longer answers.

Limits we already see. The voters are the general public and not a company's employees, and the data ends in 2025, so the newest models are not in it. We see the project as a method a company would run again with newer votes, not as a final ranking.
