4. Five-fold cross-validation on unseen sessions

=== Step 1: how the 5 folds were made (file R/resultados/auc/folds_5.csv) ===
- The unit is the SESSION (evaluation_session_id), not the row.
- Why: every vote makes 2 rows, 1 per model. If the 2 rows fell in different folds, the
  fit would have seen the vote that the test is about. A session never gets split.
- The 106,620 sessions got the labels 1 to 5 in equal numbers,
  shuffled with set.seed(2026). The code that does it (make_folds in R/11):

    {
        votes <- base[base$lado == "model_a", c("id", "evaluation_session_id")]
        sessions <- sort(unique(votes$evaluation_session_id))
        set.seed(seed)
        fold_of_session <- setNames(sample(rep_len(1:k_folds, length(sessions))), 
            sessions)
        out <- data.frame(id = votes$id, fold = unname(fold_of_session[votes$evaluation_session_id]))
        out[order(out$id), ]
    }
